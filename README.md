# PUBLICK WORLD / 会員証ジェネレーター

公開サイト：https://fukutomisota.github.io/VQVQ/

好きのあるほうへ。

名前だけ必須、ログイン不要の会員証ツールです。3つの異なる構図から選べます。HTML・CSS・Canvasで動作し、追加ライブラリや外部の画像素材・フォント・APIキーは使いません。

## 3つのスタイル

- Y3K LIQUID：墨紺の余白、右上のクロームP*、下側の大きな名前。
- HOLO IDOL：光源に反応する虹色の面、中央の記号またはポートレート、中央揃えの名前。
- 設定資料：格子、項目と値、参考画像、色指定チップ。バーコードとトンボ、紙の粒子はこのスタイルだけ。

Y3KとHOLOの文字情報は、名前・ひとこと・PUBLICK WORLDの3点に絞っています。肩書き、すきなもの、参加スタイルは設定資料と自己紹介文で使えます。画像がある場合は各構図のアイコン枠へ配置します。

## 使い方

1. 呼ばれたい名前を入力します。肩書き、すきなもの、ひとこと、参加スタイルは任意です。
2. 入力が反映されるミニカードからスタイルを選びます。
3. 必要ならアイコンを選び、拡大率と左右・上下の位置を調整します。
4. 「PNGを保存する」で1600×1000pxの画像を保存します。「画像を表示」では長押し用の画像を開きます。
5. 「自己紹介文をコピー」で名前などを整えた文章をコピーできます。コピーできない場合は、選択できる文章を表示します。
6. 「Discordへ」で招待画面を別タブで開きます。画像や文章は自分で投稿します。

名前32文字、肩書き18文字、すきなもの48文字、ひとこと60文字。画像はPNG・JPEG・WebP、12MB以下・4000万画素以下です。

## 光と描画

クロームP*は文字の距離場から高さと法線を作り、仮想点光源、距離減衰、鏡面反射、周囲の光の反射を近似します。HOLOは面法線、光の入射角、薄膜色の位相を計算します。実物の完全な光学シミュレーションではありません。

指・マウスによる傾きに合わせて光源位置を変え、主プレビューのCanvasを描き直します。サムネイルは標準の光源を保ちます。光源更新は最大30回/秒に抑えていますが、スマホ実機の速度を保証するものではありません。端末の傾きセンサーや追加の権限は使いません。

PNGは基準の光源で静止画として書き出します。保存後は一度だけカードの傾きと光源が動きます。動きを減らす設定では、ポインターの照明変化と保存演出を止めます。

光沢系に粒子は重ねません。設定資料だけに紙の質感を残しています。

## 入力の記憶

初期状態では記憶しません。「この端末に覚える」を選ぶと、名前・文章・参加スタイル・デザインの選択をブラウザ内に保存します。アイコンやその位置、動的な光源は保存しません。

再訪時は前回の入力を復元します。チェックを外すか「保存した内容を削除」で、このツールの保存データを削除できます。現在の入力は残ります。以前のデザイン選択は、近い構図または既定のスタイルへ移行します。

入力・画像処理は端末内で行い、外部へ送信しません。Discordボタンを押すとDiscordの画面を開きます。招待URLに入力内容を含めません。

## ブランドと公開

PUBLICKの綴りは造語として維持。P*をページ、カード、favicon、OGPに共通で使います。OGP画像は同じクロームP*の描画処理から1200×630pxで生成します。

`config.js` が会名・招待URL、`tokens.js` が色・文字・余白・素材設定です。GitHub Pagesのmainブランチのルートから公開します。ZIPを展開してindex.htmlを直接開くこともできますが、ローカルファイルでは記憶やコピーが制限される場合があります。

## 確認

Microsoft Edgeと既存のPlaywrightで、3種類のPNG、最大文字数と画像調整、光源による画素変化、ポインター時の主画面だけの再描画、動きを減らす設定、記憶・削除、コピーの代替表示、画面幅320〜1280px、OGPの寸法を確認しています。iPhone・Android実機の速度や保存メニューは未確認です。

UI UX Pro Maxの読みやすさ・操作領域・フォーカスの指針と、Sitesの静的サイト向け手順を参照しています。構図とブランド表現は今回の個別指示を優先しています。

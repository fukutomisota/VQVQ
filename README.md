# PUBLICK WORLD / 会員証ジェネレーター

公開サイト：https://fukutomisota.github.io/VQVQ/

紙・粒子・重ね刷り・切り抜きと、大きな名前の文字を組み合わせた会員証ツールです。静的HTML・CSS・Canvasのみで動作し、サイト本体に追加ライブラリや画像素材、外部フォントはありません。

## 使い方と機能

1. 呼ばれたい名前を入力します。肩書き、すきなもの、ひとこと、参加スタイルはお好みで。
2. 横スクロールする実物のミニカードからスタイルを選びます。
3. 必要ならアイコンを選び、拡大率と左右・上下の位置を調整します。
4. 「PNGを保存する」で1600×1000pxの画像を保存します。
5. 保存できない端末では「画像を表示」から長押し保存を試せます。
6. 「Discordへ」または「Discordへ進む」で招待画面を別タブで開きます。会員証の自動投稿は行いません。

名前32文字、肩書き18文字、すきなもの48文字、ひとこと60文字。対応画像はPNG・JPEG・WebP、12MB以下・4000万画素以下です。HEICはJPEGなどに変換して選んでください。

入力内容や画像は外部送信・永続保存しません。会員資格の認証・正式な番号の採番・スタンプ管理は含みません。

## 7つの印刷スタイル

1. Y3K LIQUID：墨紺の背景と流れるクローム。名前は明るく大きく、液体金属はアイコンの周囲に。
2. STICKER BOMB：白い切り抜きシール、回転と影、手描き風の落書き。
3. TYPE POSTER：端からはみ出す巨大な名前、白黒と蛍光色、細い罫線。
4. GRAIN FIELD：ざらつく色の溶け合い、フィルム枠、手書き風の発行日。
5. SPEC SHEET：等幅文字、格子、項目と値、ステータス部品。
6. PAPER CUT：重ねた紙、欠けた角、淡い影、落ち着いた色。
7. MATTE FOIL：墨色の紙、名前だけの金属グラデーション、広い余白。

## 共通のデザイン設定

`tokens.js` の `TACTILE_TOKENS` が共通設定です。

- `colors`：紙・墨・ピンク・ブルー・黄色、明暗モードの文字と背景。
- `fonts` / `type`：書体と文字階層。カードの名前は標準200px（カード高さの20%）。
- `space` / `layout`：ページの余白、入力枠、操作領域、ミニカードなど。
- `card`：1600×1000px、共通余白と文字の行間。
- `texture`：256pxノイズタイル、ページ7.5%、カード8.5%、GRAIN FIELD12%、MATTE FOIL7.5%、Y3K LIQUID2.5%。
- `motion`：紙めくり260ms、押したときの反応180ms。
- `styles`：7種類それぞれの色。

ページのCSS変数とCanvas描画の両方がこの設定を参照します。固定プレビューと保存バーの実測高さは、入力欄を隠さないために動的に反映します。暗い表示設定と「動きを減らす」設定にも対応します。キーボード表示で画面が狭くなった際はプレビューを小さくします。

## 会名・招待URL・表示番号

`config.js` の `communityName`、`communityEnglish` で会名を変更できます。`discordInviteUrl` がDiscordボタンのリンク先です。現在は `https://discord.gg/tt7rj6W7Q`。ボタンは名前の入力や保存前でも使えます。入力・画像をURLに含めません。`memberNumber` は表示用の共通番号（初期値 `0001`）です。重複のない正式な会員番号を自動発行する仕組みではありません。発行日は端末の日時をAsia/Tokyoとして表示します。

## 公開とローカル利用

GitHub Pagesはmainブランチのルートを公開元にしています。このフォルダーの中身をリポジトリのルートに置きます。ビルド・APIキー・サーバー側の処理は不要です。

ZIPを展開し、`index.html` をブラウザで直接開いても操作できます。

## 確認

PC版Edgeで、7種類のPNG、全入力欄の文字数制限、画像読み込み・位置調整・削除、PNG保存、画像表示、390pxと1280pxの明暗表示、320〜1280pxでのはみ出し、固定プレビュー、キーボードを想定した狭い画面、キーボード操作、reduced-motion、外部通信がないことを確認しました。

文字色と背景の基本トークンの組み合わせは4.5:1以上です。これは全ての画像・装飾・アンチエイリアスを含む画素単位の認証や、実機スクリーンリーダー試験を意味しません。iPhone・Android実機での保存は未確認です。

## 制作に使用したもの

UI UX Pro Maxの文字階層・コントラスト・フォーカスを隠さない設計の指針と、Sitesの静的サイト向け手順を使用しました。具体的なビジュアルはユーザー指定のTACTILE TYPEを優先しています。検証は既存のPlaywrightとMicrosoft Edgeで行いました。新しい依存関係は追加していません。

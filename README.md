# 会員証ジェネレーター

スマホ・PCのブラウザで会員証を作る、追加ライブラリ不要の静的Webサイトです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 名前、肩書き、好きなもの、ひとことを入力します。
3. 7つのスタイルから選び、必要ならアイコン画像を選びます。
4. 「PNGを保存する」で1600×1000pxの画像を保存します。
5. 保存できない場合は「画像を表示」を押し、表示された画像を長押しするか、ブラウザの画像保存機能を使います。

名前は32文字、肩書きは18文字、好きなものは48文字、ひとことは60文字までです。名前は必須です。画像はPNG・JPEG・WebP、12MB以下、4000万画素以下に対応します。HEIC画像は写真アプリなどでJPEGに変換してから選んでください。

## 7つのスタイル

- Aesthetic × Y3K：パステル、グリッド、金属のリング
- Neo Kawaii × Glass：ピンクとグリーン、ハート、半透明のパネル
- Cyber × Chrome：濃いブルー、金属のリング、細いグリッド
- Dream × Aurora：光の帯、星空、深い色のパネル
- Pixel × Internet：方眼、ピクセル、レトロなウィンドウ
- Soft × Pop：アプリコット、丸い図形、やわらかい色
- Mono × Hologram：グレー、虹色のリング、斜めのライン

## 会名を変更する

`config.js` の次の3項目を編集します。画面とPNGの会名が同時に変わります。

```js
window.CARD_CONFIG = Object.freeze({
  communityName: 'インターネットVちゅー会',
  communityCaption: 'すきなことから、つながろう。',
  filePrefix: 'internet-membership-card',
});
```

## GitHub Pagesで公開する

1. GitHubに公開リポジトリを作成します。
2. **このフォルダーの中身**をリポジトリの一番上へアップロードします。`index.html` が一番上にある状態にします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
5. `Branch` は `main`、フォルダーは `/(root)` を選んで `Save` を押します。
6. デプロイ完了後、Pages画面に表示されたURLをDiscordに置きます。

詳しい設定方法： https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

ビルド・パッケージのインストール・APIキー・独自サーバーは不要です。独自ドメインを使わなければ、GitHub Freeの公開リポジトリ向けPagesで運用できます。

## データの扱い

- 名前などの入力情報と選択画像は、ブラウザのメモリ内で処理します。
- 外部API、解析ツール、CDN、外部フォントへの通信はありません。
- 入力情報や画像をサーバー・ブラウザの永続ストレージに保存しません。入力内容・選択画像の復元機能はありません。
- 会員の所属確認、会員番号、参加履歴、スタンプの管理機能は含みません。この版は自己紹介用の画像を作るツールです。
- Webページ自体の配信には、公開先サービスの通常のアクセス記録が適用されます。

## 確認したこと

Windows版Microsoft Edgeで実施：

- 7種類のPNGダウンロードと画像サイズ（1600×1000px）
- 入力の反映、文字数制限、日本語・絵文字の入力
- アイコン読み込み、拡大・位置調整、中央に戻す、画像を外す操作
- 非対応データと大きすぎるファイルのエラー表示
- 320・375・390・768・1024・1440px幅で横スクロールが出ないこと
- 画像表示ダイアログとキーボード操作、動きを減らす設定
- 端末内のHTMLを直接開いた場合のPNG保存
- 入力・画像処理に外部通信が発生しないこと

画面幅の確認はPCブラウザでの再現です。実機のiPhone Safari・Android・Discord内ブラウザでの保存は未確認です。公開後は各端末での確認を推奨します。

## 使用したスキルとツール

- UI UX Pro Max：画面構成、ガラス表現・未来的な質感の参考、読みやすさ、タップ領域、ドラッグ以外の操作方法を検討。
  https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- Skill Installer：上記のスキルをプロジェクト内の `.agents/skills/` に導入。公開用フォルダーには含めていません。
- Sites：静的HTML/JavaScriptの準備とローカルプレビュー・検証の手順を使用。Sitesへの登録やホスティングは行っていません。
- 既存のPlaywrightとMicrosoft Edge：ブラウザ操作とPNG保存の確認。サイト本体の依存関係には含めていません。

最初のデザイン検索には紹介ページ向けの構成も含まれていたため、レビューや推薦文などは採用していません。カード作成ツールに必要な画面構成を個別に設計しています。Y3Kなどの7つのカード背景と装飾は、このサイト向けにCanvasで実装したものです。

# PUBLICK WORLD / 会員証ジェネレーター

公開サイト：https://fukutomisota.github.io/VQVQ/

静かなダーク基調のページから、6種類の会員証をつくるツールです。静的HTML・CSS・Canvasのみで動作します。画像素材・外部フォント・追加ライブラリ・APIキーは使いません。

## 使い方

1. 呼ばれたい名前を入力します。肩書き、すきなもの、ひとこと、参加スタイルは任意です。
2. 入力が反映されるミニカードからスタイルを選びます。
3. 必要ならアイコンを選び、拡大率と左右・上下の位置を調整します。
4. 「PNGを保存する」で1600×1000pxの画像を保存します。「画像を表示」では長押し用の画像を開きます。
5. 「自己紹介文をコピー」で名前などを整えた文章をコピーできます。コピーが使えないブラウザでは、選択できる文章を表示します。
6. 「Discordへ」で招待画面を別タブで開きます。画像や文章は自分で投稿します。

名前32文字、肩書き18文字、すきなもの48文字、ひとこと60文字。画像はPNG・JPEG・WebP、12MB以下・4000万画素以下です。

## 入力の保存

初期状態では入力を記憶しません。「この端末に覚える」を選ぶと、名前・文章・参加スタイル・デザインの選択だけをブラウザのlocalStorageに保存します。アイコンやその位置は保存しません。

次回は前回の入力を復元し、「おかえり、〇〇さん。」と表示します。チェックを外すか「保存した内容を削除」で、このツールの保存データを削除できます。現在の入力はそのまま残ります。保存が使えない環境でも会員証をつくれます。

入力・画像処理は端末内で行い、外部送信はしません。Discordボタンを押すとDiscordの画面を開きます。招待URLに入力内容を含めません。正式な会員番号を発行する仕組みはなく、番号欄を削除しています。

## 6つのスタイル

- Y3K LIQUID：流れるクロームと大きな白文字。
- HOLO IDOL：ホロ箔の推しカード。文字の下には読みやすい面を確保。
- 設定資料：設定画の罫線、色指定チップ、参考画像の枠。三面図のガイドは装飾で、ユーザー画像から別角度を生成しません。
- STICKER BOMB：白い切り抜きシールと落書き。
- GLASS：透明な層と光の奥行き。
- TYPE POSTER：巨大文字と蛍光色。

## 共通設定

`tokens.js` に色・書体・余白・角丸・動き・カードの質感をまとめています。ページには粒子を重ねず、必要なカードにだけ質感を使います。書体は端末のシステムフォントです。

名前は標準200pxを基準に、長さに合わせて縮めます。発行日は端末日時を日本時間で表示します。カードの光沢は指・マウスの位置に反応し、PNG保存時は一度だけカードが前に出る演出を表示します。端末の傾きセンサーや権限は使いません。動きを減らす設定では演出を止めます。PNGは静止画として書き出します。

スマホではプレビューを上部に固定し、キーボードで表示領域が狭くなったときは縮小します。下部の保存ボタンを残しています。

## ブランド・招待URL

`config.js` の `communityName` / `communityEnglish` が会名、`discordInviteUrl` が参加先です。PUBLICKの綴りを維持しています。

## 公開

GitHub Pagesのmainブランチのルートから公開します。このフォルダーのファイルをリポジトリのルートへ置きます。ZIPを展開してindex.htmlを直接開くこともできます。ブラウザによってはローカルファイルでの記憶やコピーに制限があります。

## 検証環境

既存のMicrosoft EdgeとPlaywrightで16項目の検証を通過しています。画面幅320〜1280px、6種類のPNG保存、画像調整、文字数制限、記憶の選択・復元・削除・保存できない場合、コピーの成功・失敗、動きを減らす設定を確認しました。コピーの成功・拒否はテスト用APIで再現し、実際のアプリ内ブラウザでもコピー成功の表示を確認しています。実機のiPhone・Androidの保存メニューは未確認です。

UI UX Pro Maxの余白・文字階層・フォーカス・コントラストの指針と、Sitesの静的サイト向け手順を参照しています。ユーザー指定のビジュアルとGitHub Pagesの公開先を優先しています。
